# TOTEM — Colemak-DH

Personal migration of the five-layer QMK `home_row_3x5_colemak_dh_mode` layout
for the wireless GEIST / KeebSupply TOTEM (Seeed XIAO BLE).

See [MIGRATION.md](MIGRATION.md) for physical key order, source references,
build/flash instructions, and the explicit QMK/ZMK behavior differences.

- Five user layers plus two mouse-speed overlays.
- Auto Shift, home-row modifiers and thumb layer-taps at 175 ms.
- Mouse movement, wheel, buttons, media and Mac shortcuts.
- ZMK Studio enabled on the left/central half; outer-right key unlocks it.
- ZMK v0.3.0 and the matching GitHub Actions workflow.

Hardware definition by [GEIGEIGEIST](https://github.com/GEIGEIGEIST/TOTEM).
